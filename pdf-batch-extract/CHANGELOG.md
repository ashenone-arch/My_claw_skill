# Changelog

## v3.0 (2026-08-11)

### 新增
- **`--pages` 参数**：脚本支持 `--pages "146-278"` 指定页码范围精准提取，不再强制全量
- **章节感知提取工作流**：新增"目录扫描 → 定位页码 → 精准提取"流程，覆盖招股书/年报的分节提取场景
- **轻量场景短路**：目标页 ≤ 20 且无需表格时，直接使用 `read(pages="x-y")` 工具，不调脚本
- **`EXTRACTION_STRATEGIES.md`**：按需查阅的参考文件，包含策略决策树、章节感知流程、subagent 模板、港股/A股结构对照
- **`CHANGELOG.md`**

### 变更
- **水印处理降级为按需触发**：不再默认执行步骤 1.5，仅当用户提及或 MD 中有明显水印碎片时才触发
- **水印内容移至 WATERMARK.md**：从 SKILL.md 主流程中移除，保留专项文件供按需参考
- **SKILL.md 瘦身**：移除冗长的 subagent prompt 模板、水印流程、章节对照表，精简约 30%
- **QUICKREF.md 更新**：补充 `--pages` 用法、章节感知场景、章节结构速查表

### 脚本变更
- `process_single_pdf()` 新增 `page_range` 参数
- 新增 `parse_page_range()` 解析页码范围
- 使用 argparse 替代原始的 `sys.argv` 解析
- 输出格式新增第四项 `|<实际提取页数>`，区别于 PDF 总页数

### 向后兼容
- 不带 `--pages` 时行为与 v2.0 完全一致
- subagent prompt 模板保持 100% 兼容
- 输出格式新增字段为尾部追加，解析脚本无需修改
