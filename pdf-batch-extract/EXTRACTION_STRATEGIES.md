# 提取策略参考

> 本文档为 pdf-batch-extract 的**按需查阅**参考，不随主流程默认加载。

---

## 策略决策树

```
用户请求
├── 指定了章节/节名？
│   ├── 是 → 章节感知提取
│   │   ├── 目标页 ≤ 20 → 直接用 read(pages="x-y") 读取，不调脚本
│   │   ├── 目标页 > 20 → extract_pdf_to_md.py --pages "x-y"
│   │   └── 需要表格格式化 → extract_pdf_to_md.py --pages "x-y"（read 工具不保留表格）
│   └── 否 → 全量提取
│       ├── PDF ≤ 2 个 → 主流程直接调脚本
│       └── PDF ≥ 3 个 → 分批 subagent 并行
└── 有水印？→ 参考 WATERMARK.md
```

## 章节感知提取工作流

### 场景：用户要求提取招股书/年报的特定章节

**步骤 1：目录扫描定位页码范围**

用 `read(pages="1-20")` 读取 PDF 前 20 页，从目录区域定位目标章节的起止页码。

常见金融文档章节结构：

| 文档类型 | 业务/竞争节 | 财务/会计节 | 注意事项 |
|----------|-----------|------------|---------|
| A股招股书（常规） | 第六节 业务与技术 | 第八节 财务会计信息 | 部分公司章节编号不同（如大普微：第五节/第六节） |
| 港股招股书 | 業務 | 附錄一 會計師報告 | 正文中"財務資料"节是管理层分析，**会计政策在附錄一** |
| 年报 | 第三节/第四节 管理层讨论与分析 | 第十节/第十一节 财务报告 | 注意年报章节结构因交易所而异 |
| 科创板招股书 | 第六节 业务与技术 | 第八节 财务会计信息 | 与A股主板相同 |

**步骤 2：精准提取目标节**

```bash
# 全量提取（无 --pages）
python extract_pdf_to_md.py "file.pdf" "output_dir/"

# 指定页码范围
python extract_pdf_to_md.py "file.pdf" "output_dir/" --pages "146-278"

# 轻量场景（≤20 页，无需表格格式化）
# 直接用 read(pages="146-165") 读取，跳过脚本
```

**步骤 3：子 agent 结构化提取（如需分析而非纯原文）**

当用户最终目标是"对比分析各公司的XX"而非"保存原文"时，子 agent 的 prompt 应包含：
- 页码范围
- 需要提取的具体信息维度
- 输出格式（MD 文件路径）
- 跳过内容（如"跳过行业概述"）

## Subagent Prompt 模板

### 全量提取 subagent（每 agent 处理 1 个 PDF）

```
你负责调用通用脚本提取 PDF 为 markdown。

调用命令（直接在 bash 中执行，不要写 Python 代码）：
"C:\Program Files\AlphaEngine\resources\python\python\python.exe" "{技能目录}/scripts/extract_pdf_to_md.py" "{pdf_path}" "{output_dir}"

执行后解析输出：
- 成功：输出格式为 "OK|<md文件路径>|<总页数>|<表格数>|<实际提取页数>"
- 失败：输出格式为 "ERROR|<错误信息>"

完成后汇报：文件名、页数、表格数、md 文件路径（或失败原因）。
```

### 章节感知 subagent（每 agent 处理 1 个公司的 1-2 个节）

```
你负责从 PDF 的特定章节提取信息。

工作步骤：
1. 用 read(pages="起始-结束") 读取目标节，每次最多 20 页，分多次读完
2. 提取以下维度的关键信息：[用户指定的维度列表]
3. 写入结构化 MD 文件到 [输出路径]

注意事项：
- 只提取公司自身描述部分，跳过行业整体介绍
- 标注来源页码
- 引用原文关键表述
```

## 水印处理

水印检测和清理的完整指引见 `WATERMARK.md`。

水印处理改为**按需触发**：
- 用户未提及水印 → 跳过
- 提取后的 MD 中明显出现水印碎片 → 询问用户是否需要清理
- 用户明确要求清理水印 → 按 WATERMARK.md 执行

## 港股/A股招股书章节结构对照

| 内容 | A股招股书 | 港股申请版本 |
|------|---------|------------|
| 公司业务描述 | 第六节 业务与技术 | 業務 |
| 行业概况 | 第六节 二、行业基本情况 | 行業概覽（独立章节） |
| 竞争优势 | 第六节 一、主营业务+六、技术水平 | 業務 内嵌 |
| 财务会计信息 | 第八节 财务会计信息与管理层分析 | 財務資料（管理层分析） |
| 会计政策详情 | 第八节 四、主要会计政策 | **附錄一 會計師報告** |
| 历史沿革 | 第五节 发行人基本情况 | 歷史、發展及公司架構 |
| 风险因素 | 第四节 风险因素 | 風險因素 |

> 关键差异：港股招股书的详细会计政策在**附錄一**（独立页码系统，如 I-1），不在正文"財務資料"节。A股的会计政策在第八节内嵌。

## 注意事项

- 脚本输出新增第四项 `|提取页数`，与 PDF 总页数区分
- `--pages` 参数不做越界保护外的校验，页码不存在时脚本自动 clamp 到有效范围
- 轻量场景优先用 `read` 工具，避免不必要的脚本调用和 MD 文件产生
