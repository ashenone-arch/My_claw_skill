# 快速参考表

## 场景决策

| 场景 | 操作 |
|------|------|
| 用户只给了一个 PDF 文件路径 | 用 read 工具直接读取，无需触发 skill |
| 用户说"批量提取这个文件夹的 PDF" | 触发 pdf-batch-extract skill，全量提取 |
| 用户说"只提取第X节/第X-X页" | 章节感知提取 → `--pages "x-y"` |
| 目标页数 ≤ 20 且无需表格 | 直接用 `read(pages="x-y")`，不调脚本 |
| 目标页数 > 20 或需要表格 | `extract_pdf_to_md.py --pages "x-y"` |
| PDF 有表格要保留 | 脚本自动格式化表格为 Markdown |
| PDF 有水印 | 按需处理：无明显干扰则跳过；否则参考 WATERMARK.md |
| PDF 数量 ≤ 2 | 主流程直接执行脚本 |
| PDF 数量 ≥ 3 | 并行启动 subagent，每个处理 1 个 PDF |
| 已有同名 .md 文件 | 提示用户确认是否覆盖 |
| 某个 PDF 失败 | 不阻断，继续处理其他 PDF，最终汇总报告 |

## 脚本用法

```bash
# 全量提取
python extract_pdf_to_md.py "file.pdf" "output_dir/"

# 指定页码范围
python extract_pdf_to_md.py "file.pdf" "output_dir/" --pages "146-278"

# 单页
python extract_pdf_to_md.py "file.pdf" "output_dir/" --pages "15"
```

## 输出解析

```
OK|<md文件路径>|<PDF总页数>|<表格数>|<实际提取页数>
ERROR|<错误信息>
```

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| `ModuleNotFoundError: pdfplumber` | 执行环境预检安装 |
| 扫描件 PDF（无文字层） | 提示用户这是扫描件，建议 OCR |
| 密码保护 PDF | 跳过并记录失败 |
| 同名 .md 已存在 | 询问用户是否覆盖 |
| 中文路径报错 | Python 3.13+ 原生支持，传绝对路径 |
| 页码范围超出 PDF 实际页数 | 脚本自动 clamp 到有效范围 |
